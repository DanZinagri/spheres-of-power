# Spheres of Power Wiki — Mirror

An Obsidian vault + [Quartz](https://quartz.jzhao.xyz) site mirroring
[spheresofpower.wikidot.com](https://spheresofpower.wikidot.com), which publishes its content under the
**Open Game License v1.0a** (see `content/Meta/Legal and Open Game License.md`, which must stay in
the mirror — OGL §10 requires a copy of the license with every copy of the Open Game Content).

## Layout

| Path | What it is |
| --- | --- |
| `content/` | The Markdown vault. Open this folder in Obsidian. |
| `scripts/scrape.py` | Downloads the wiki and converts it to Markdown. |
| `.cache/` | Raw HTML cache (git-ignored, re-downloadable). |
| `quartz.config.ts`, `quartz.layout.ts` | Site configuration. |
| `.github/workflows/deploy.yml` | Builds and publishes to GitHub Pages on push to `main`. |

Notes are named after page titles and grouped into folders by the wiki's breadcrumbs. Pages the wiki
never parented are in `Archetypes (Unsorted)` or `Other Pages`. Every note's frontmatter has `source`
(the original URL), `updated` (last edit on the wiki), `parent`, and `tags`. Links between pages are
`[[wikilinks]]`, including links to specific headings.

## Resync from the wiki

```bash
python scripts/scrape.py
```

Only pages whose sitemap `lastmod` changed are re-downloaded. The converter only deletes notes it
generated itself (marked with `<!-- generated by scripts/scrape.py -->`), so your own notes in
`content/` are safe. **Edits you make to generated notes are overwritten on resync** — remove the
marker comment from a note to stop the scraper touching it.

Requires Python 3.10+ and `pip install requests beautifulsoup4 markdownify lxml`.

### Images

Wiki-hosted images are book covers and banners (publisher trade dress, not Open Game Content), so
by default they are replaced with "Source: [Book](store link)" lines. `python scripts/scrape.py
--images` downloads them into `content/attachments/` if you want them in a private vault.

## Preview the site locally

```bash
npm ci
npx quartz build --serve
```

Then open http://localhost:8080.

## Publish to GitHub Pages

1. Create an empty GitHub repo and push this one to it (`git remote add origin <url>`, `git push -u origin main`).
2. In the repo: **Settings → Pages → Source: GitHub Actions**.
3. Set `BASE_URL` in `site.ts` to `<user>.github.io/<repo>` (or your custom domain).

Every push to `main` rebuilds the site. Other hosts (Cloudflare Pages, Netlify, Vercel) work too:
build command `npx quartz build`, output directory `public`. See https://quartz.jzhao.xyz/hosting.

## Updating Quartz itself

The original Quartz repo is the `upstream` remote: `npx quartz update`.
